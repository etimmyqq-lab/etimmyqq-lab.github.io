用 Claude Code 做什麼，不做什麼

去年十二月，一個做健康食品訂閱盒的創業者傳訊息給我，時間是晚上十一點四十分。

他說他剛起了一卦，得到屯卦，查了很多解說，每一篇都寫「艱難」「險阻」「舉步維艱」，看完整個人都不對了。然後他問我：「老師，是不是代表我的新創已經沒救了？」

我回他三個字：你查錯了。

屯卦的「屯」這個字，古字形是一顆種子卡在土裡，上面一根嫩芽正在用力往上鑽的樣子。是破土的那一刻，不是種子壞掉了。

後來我們打電話，聊了快五十分鐘。

他做的是高雄在地食材的健康訂閱盒，從食材採購到菜單設計到每週宅配，全部自己來。公司就他跟兩個朋友，三個人，創業七個月，月營收剛剛站上十二萬，但每個月要花十八萬。那個缺口讓他每天晚上睡不好。

「你問我能不能撐住」，他說，「我自己都不確定。」

---

屯卦的卦辭是：勿用有攸往，利建侯。

翻成白話，大致是：不要急著去哪裡，現在最有利的事情是建立你的根據地。

這不是在說你很慘，是在說你現在這個階段，往外衝是錯的，往內紮是對的。

很多人查到「屯」就看到「艱難」兩個字，就覺得卦在否定自己。但屯卦的象傳說的是「雲雷屯，君子以經綸」——雲和雷在天地之間醞釀，是在準備一場雨，不是在說這片天就要塌了。

我問他：你七個月下來，摸出什麼東西是有效的？

他停了一下，說：「我知道什麼樣的客人會持續訂，什麼樣的客人訂一次就消失了。」

我說，這個就是你現在最值錢的東西。不是你的產品，是你對這群人的理解。把這件事記下來、說清楚、整理成你的決策邏輯，這才是屯卦在告訴你做的事。

用 Claude Code 做什麼，不做什麼

後來我幫他做了一件事：把他腦袋裡那套「誰會留、誰不會留」的直覺，用 Claude Code 輔助整理成一份結構化的客戶判斷文件。

不是要讓 AI 幫他做決定，是讓他說清楚他自己在怎麼做決定。

光是這個整理過程，他就發現幾件之前沒有意識到的事：他的長期客人大多是家裡有小孩的雙薪家庭，他的流失客人大多是剛開始嘗試健康飲食、但還沒養成習慣的單身族。這兩群人需要的行銷語言根本不一樣，但他一直在用同一套文案說話。

他說：「整理完之後我有點嚇到，這些我其實都知道，但就是沒有講出來過。」

這就是 Claude Code 在屯卦階段能做的事：不是替你跳過艱難，是幫你把你在艱難裡學到的東西沉澱下來。

---

很多創業者來找我談企業 AI 導入，開場白是「老師我想用 AI 來讓公司成長更快」。這個出發點沒錯，但時機的判斷很重要。

如果你還在屯卦的階段——還沒搞清楚你的客人是誰、你的核心服務是什麼、哪些流程是有效的——這個時候導入 AI 的結果通常是：你把不確定的事情加速了。速度加快，但方向還是模糊的。

屯卦說的「勿用有攸往」，在 AI 導入的語境裡可以翻成：先別急著自動化你還沒搞懂的流程。

就這樣。

屯卦之後呢？

屯卦之後的卦是蒙卦，是蒙昧待學，開始學習、建立知識的階段。然後是需卦，等待時機、積累能量。

這個順序不是說你要一直等、一直忍，是說每個階段有每個階段該做的事。急著跳過去，不是勇敢，是種子還沒長根就想要開花。

那個做健康食品訂閱盒的創業者，現在三個月過去了。月營收從十二萬爬到二十一萬，缺口從六萬縮到剩兩萬多。他沒有引進什麼大型系統，就是把腦袋裡的東西整理清楚了，然後按照那個邏輯調整了行銷方向。

他上個月傳訊息說：「老師我覺得我知道下一步要做什麼了。」

我回他：那就可以開始考慮 AI 工具了。

常見問題

起卦得到屯卦，是不是代表我現在做的事情方向根本是錯的？
不一定。屯卦的核心意象是種子破土，艱難是這個過程的正常狀態，不是「你選錯了」的訊號。它更像是在問：你有沒有在紮根？而不是在評判你的方向對不對。如果你問的是新創或新業務是否可行，屯卦更多在提醒你：現在不是擴張的時機，是把基礎打穩的時機。
屯卦說「勿用有攸往」，那我在屯卦階段什麼都不能做嗎？
不是靜止不動，是不要急著「往外」——不要這個時候大規模擴張、急著找新市場、急著多招人。屯卦說的「利建侯」是建立根據地。翻成白話是：把現有客人服務好、把有效的流程記錄下來、把你已經學到的東西整理清楚，這些都是屯卦鼓勵你做的事。
屯卦階段適合導入 AI 工具嗎？
適合，但用的方式要對。屯卦階段適合用 AI 做的，是整理你的知識和判斷邏輯——用 Claude Code 幫你把腦袋裡的決策說清楚、把你的客戶模式分析出來。不適合的是用 AI 大量自動化你還沒搞清楚的流程，因為那會把混亂放大，不是把效率拉高。
