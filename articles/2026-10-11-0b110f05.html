你需要認的英文只有四個

Claude Code 可以全中文操作，你用中文打字它就用中文回你。整個流程裡你真正需要認得的英文，我在課堂上幫學員數過，四個：`/init`、`/clear`、`yes`、`no`。其他全部可以用中文講。

上週六下午我在彰化一家做農機零件的工廠上課，來的是二代接班的廠長，42 歲，高職機械科畢業，他自己說英文考試從沒及格過。十二個人的課，他坐最後一排，第一句話問的是：「老師，這個黑黑的畫面，是不是全部都要打英文？」

我把筆電轉過去，請他直接用中文打他現在最煩的那件事。他打了這句：

「幫我把這個資料夾裡的報價單 Excel 整理成一張總表」

二十三個字，全中文。四十秒後總表出來了。他看著螢幕沒講話，過了幾秒才說：「我以為要打英文。」

這個誤會我這兩年遇到太多次，而且卡住的人通常不是不會用電腦，是被「黑色畫面加英文」這個印象嚇退的中年主管。所以這篇就把話講明白。

你需要認的英文只有四個

Claude Code 的介面分兩種東西：你跟它說的話，跟系統的指令。

說的話，中文完全沒問題。你要它改程式、整理檔案、讀一份 PDF 寫摘要、把資料夾裡的檔名統一改格式，全部用中文講，講得越白越好。「把這個 py 檔裡面寫死的路徑改成讀環境變數」這種半中半英的也行，它看得懂。

系統指令是斜線開頭的，那幾個是固定英文字母，沒辦法翻成中文。但實務上你每天會用到的只有：

`/init` 第一次進一個專案時打，它會自己把整個資料夾讀過一遍，然後寫一份專案說明檔。

`/clear` 聊到一半想重新開始、或是它開始答得很怪的時候打，清掉對話記憶。

另外兩個不是指令，是它問你要不要執行某個動作時，你回的 `yes` 跟 `no`。這兩個字我相信大家都認得。

就這四個。其他像 `/compact`、`/help`、`/model` 這些，知道有就好，不會用也不影響你做事。

讓它每次都回中文，不要每次都拜託它

這是最多人踩的地方。一開始它可能回中文，聊久了、或是遇到程式碼的時候，它會開始夾英文，甚至整段英文。然後學員就在那邊一直打「請用中文」。

不用每次拜託。在你的專案資料夾裡建一個檔案，名字叫 `CLAUDE.md`，裡面寫：

常見問題

我用中文問，它回我英文怎麼辦？
直接跟它說「請用繁體中文回答」就好，它會記住。真的常常跑掉的話，在專案根目錄的 CLAUDE.md 裡寫一行「所有回覆使用繁體中文」，之後每次開啟都自動套用。我自己的 CLAUDE.md 第一行就是這句，寫了之後再沒跑掉過。
那些斜線指令我記不住，有辦法看嗎？
打一個斜線 `/` 就會跳出清單，上下鍵選。真的不用背。我課堂上的廠長第二節課就發現這件事，他說早知道就不用在紙上抄。要查全部功能打 `/help`，不過老實講你前兩個月大概只會用到 `/init` 和 `/clear` 兩個。
檔名跟資料夾有中文，會不會出問題？
不會。「報價單彙總表.xlsx」「客戶資料」這種路徑它讀得懂，中文檔名照樣處理。那位廠長的工廠檔案全是中文命名，整理總表那次沒出任何狀況。要注意的反而是路徑裡有空格的時候，講清楚是哪個資料夾比較保險。
