先搞懂它要站在什麼上面

一台剛開封的 MacBook 攤在會議桌上，一個做手工皮件的大姐坐我旁邊，手指在觸控板上滑得還不太順。她說：老師，Claude Code 我裝了三次都失敗，畫面一直跳一行紅字，說找不到 npm。npm 是要另外花錢買的嗎？

我先講結論：Mac 新手裝 Claude Code，卡住的幾乎都不是 Claude Code 本身，是它底下要先鋪好的那一層。你想直接請正主進門，可是系統回你一句：地基還沒打，人進不來。

先搞懂它要站在什麼上面

Claude Code 是一個在「終端機」裡跑的工具。終端機就是 Mac 內建那個黑底白字、要打指令的視窗，你在 Launchpad 搜「終端機」或「Terminal」就找得到。很多人第一次看到它會怕，覺得這是工程師的東西。其實你把它想成一個「用打字代替點滑鼠」的視窗就好。

Claude Code 是透過一個叫 npm 的東西安裝的。npm 不用花錢，它是 Node.js 這套環境自帶的套件管理員。講白一點：Node.js 是地基，npm 是地基附贈的搬運工，Claude Code 是你要住進去的房子。你直接搬房子進來，可是地基不存在，系統當然跟你說「找不到 npm」。

所以順序是這樣：先裝 Node.js，npm 會跟著進來，最後才裝 Claude Code。三步，不能跳。

三步，照著打

第一步，裝 Node.js。最單純的方式是去 Node.js 官網（nodejs.org）下載給 Mac 的安裝檔，副檔名是 .pkg，下載完點兩下，一路按繼續就好，跟裝一般 App 一樣。裝完之後，打開終端機，打這行確認：

`node -v`

它如果回你一個像 v20.11.0 的版本號，代表地基好了。版本只要是 18 以上都能用。

第二步，裝 Claude Code。同樣在終端機裡，打這行：

`npm install -g @anthropic-ai/claude-code`

那個 -g 是「裝到全機器都能用」的意思。按下 Enter 之後它會跑一陣子，跑個一兩分鐘很正常，不要以為它當掉了就把視窗關掉。

第三步，啟動。打：

`claude`

第一次啟動它會請你登入 Anthropic 帳號，照著畫面走，用瀏覽器授權一下就接起來了。到這裡你就能在終端機裡跟它對話、請它幫你看檔案、改東西。

那位大姐卡在哪

回到開頭。她三次失敗，是因為她跳過第一步，直接打第二步。系統裡根本沒有 npm，紅字就是這樣來的。我請她先把 Node.js 裝好，再打一次同一行指令，第四次，成了。她盯著螢幕上緩緩往下跑的白字，說了一句：原來不是我笨，是我順序錯了。

這句話我聽過太多次。這也是為什麼我做 Claude Code 教學的時候，從來不從「怎麼用」開始講，我一定先花時間講「它要站在什麼上面」。

而這裡面，其實藏著一個很東方的道理。

我做企業諮詢會用易經卦牌幫老闆問方向，很多人以為易經是拿來預測結果的。不是。易經六十四卦，排在最前面、講「開始」的那一卦叫屯卦。屯這個字，是種子頂著硬土往上鑽的樣子。屯卦的白話意思就四個字：起頭最難。難在哪？難不在正事，難在你得先把地基那些看不見、又不起眼的東西鋪好。

裝 Claude Code 這件事，剛好把屯卦演了一遍。你想做的正事是「用 AI 幫我工作」，可是你會卡住的地方，永遠是前面那些準備動作，裝 Node.js、找到終端機、搞懂 npm 是誰。這些沒有一個是「使用 Claude Code」，可是少了任何一個，正事都動不了。

我常跟老闆說，做企業 AI 導入也是同一回事。大家都想直接跳到「AI 幫我省了多少人力」那個畫面，可是真正決定成敗的，是前面沒人想碰的地基：資料有沒有整理、流程講不講得清楚、人願不願意配合。屯卦提醒你的就是這件事：別急著看果，先把根扎穩。你在裝一個工具的時候體會到的那點不耐煩，跟一家公司導 AI 卡住時的不耐煩，是同一種。

所以下次你 Mac 上裝什麼東西跳紅字，先別急著怪自己笨。多半只是有個地基還沒鋪。把順序理清楚，一步一步來，種子總會鑽出土。

常見問題

我完全不會打指令，終端機看起來好可怕，一定要用嗎？
裝 Claude Code 這一步，是的，它就是活在終端機裡的工具。但你需要打的其實只有那幾行，我上面都列給你了，複製貼上、按 Enter 就好，不用背。真正要適應的不是指令，是「打字代替點滑鼠」這個習慣。用兩三天就不怕了，我看過六十幾歲的老闆一週後打得比我還順。
Node.js、npm、Claude Code 到底誰是誰，我還是搞混？
記一個比喻就好：Node.js 是地基，npm 是地基自帶的搬運工，Claude Code 是你要住進去的房子。你裝 Node.js 的時候 npm 會自己跟進來，不用另外裝。所以你實際只做兩件事：裝 Node.js、用 npm 裝 Claude Code。
跑 npm install 那行跑很久，是不是當掉了？
大概率沒有。第一次裝跑個一兩分鐘很正常，它在背景下載東西。只要沒跳出紅色的 error 字樣，就讓它跑完，別手癢把視窗關掉。真的超過五分鐘完全不動，再關掉重打一次那行就好。
