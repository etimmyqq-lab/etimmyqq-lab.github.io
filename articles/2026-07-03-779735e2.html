Claude Code 不是另一個聊天機器人

上個月在桃園陪一家做汽車零件出口的老闆開會，快結束的時候他問了一個問題，我感覺自己已經被問了大概三十幾次了。

他說：「我知道 Claude Code 是 Anthropic 做的那個，我有裝，也試用了幾次。但我不懂程式，我現在還是不清楚，這個東西到底能幫我公司做什麼實際的事情？」

我問他，公司現在有什麼事情做起來讓你覺得最煩？

他想了一下說：「每週要整理一份給海外客戶看的出貨進度表。我助理要從系統把資料匯出，然後貼進 Excel，再手動改格式，改完還要翻成英文。大概要花三個小時。」

我說，這個 Claude Code 可以做。他說，真的嗎？

這就是大部分老闆對 Claude Code 最常見的困惑所在。它的介紹裡有很多「AI 程式助手」「自動化工作流程」這類詞，聽起來很厲害，但對一個不寫程式的人來說，完全不知道這跟自己有什麼關係。

Claude Code 不是另一個聊天機器人

先講最容易誤解的部分：Claude Code 不是只能聊天。

普通的 AI 對話工具，你輸入問題，它回答，然後就沒了。那個答案是一段文字，你還需要自己去執行、去複製貼上、去改。

Claude Code 不一樣的地方在於，它可以直接操作你電腦裡的檔案。你告訴它「去讀這個 CSV，然後產出一份格式整齊的 Excel 報告，存到這個資料夾」，它就真的去做了。你不需要看著它輸出的程式碼，不需要懂那些指令在幹嘛，你只需要確認最後的結果對不對。

那桃園的老闆最後怎樣了？

我花了大概四十分鐘陪他描述那份出貨進度表的需求：欄位名稱、英文翻譯對照、哪些欄位要加底色、客戶名稱要對應到哪個代碼。

然後我讓 Claude Code 根據他系統匯出的那份原始 CSV 寫了一個腳本。

之後他助理每週只要做一件事：把新的 CSV 丟進去，點一個按鈕，三秒後那份已經翻好英文、格式整齊的出貨表就出現了。

他助理說她不敢相信。

老實說我也覺得有點神奇，但這其實就是 Claude Code 最核心的用途之一：把一個重複的、有明確規則的人工作業，轉成一個腳本。

不懂程式的老闆，Claude Code 能做什麼？

我陪過的幾家公司，做過的事情包括：

一家餐飲集團，每週要從三家分店的 POS 系統匯出銷售資料，再手動做彙整。現在 Claude Code 幫他們寫了一個合併腳本，每週省了大概六小時。

一家做貿易的公司，長期需要把中文報價單轉成英文 PDF。以前是請兼職翻譯，現在 Claude Code 幫他們建了一個範本系統，自動生成中英對照版本。

一家小型會計事務所，需要定期從客戶的帳務系統拉資料然後整理成標準格式。Claude Code 把這個流程自動化了，準確率還比人工高。

這些都不是工程師做的事，都是業主或行政人員在操作。

有沒有做不到的事情？當然有。涉及複雜系統串接、需要深度客製化介面、或是你的需求本身不夠清楚的時候，Claude Code 幫不上太多。它的強項是「規則明確、可以描述清楚的重複作業」。

順帶一提，有時候我們也會問卦

那個桃園老闆在決定要不要投入時間學這個工具的時候，問了我一件有點不一樣的事。他說他習慣遇到大決策前抽一張易經卦牌。他抽到的是鼎卦。

鼎是古代用來煮食、供奉的器皿。卦象的意思是「改造舊有材料，產生新的用途」。

我說，你的原始資料（CSV、系統匯出）就是那個舊材料。Claude Code 幫你煮成新的東西（整齊的報告、自動化流程）。卦的意思很直白。

他說他覺得這個解法很有道理。

我不確定是卦幫了他，還是他本來就已經想通了，只是需要一個框架來確認。但不管怎樣，那三個小時後來變成了三秒，那件事是真的。

常見問題

我完全不懂程式，真的可以用 Claude Code 嗎？
可以，但前提是你要能清楚描述你要做的事。Claude Code 的核心是把「你的語言」翻譯成「電腦的語言」，所以你的需求越具體，它能幫上的忙越多。你只要說清楚「我有一份 Excel，裡面有 A、B、C 欄，我要把它整理成另一個格式」，剩下的技術部分它來處理。完全不懂程式的人用 Claude Code 幫公司做出實用工具，這種例子我看過蠻多次了。
Claude Code 跟我現在用的 ChatGPT 有什麼不同？
主要差別在「執行」這件事上。一般的 AI 對話工具會告訴你「你可以這樣寫程式碼」，然後你需要自己去找地方執行。Claude Code 是專門設計來讓 AI 直接在你電腦上操作檔案、寫程式、然後跑起來的工具，從描述到完成的距離短很多。如果你只是要問問題、寫文章、整理思路，一般對話工具和 Claude Code 都能做到。如果你想要 AI 真的幫你操作一個有輸入有輸出的工作流程，Claude Code 是專門為這件事設計的。
花多久時間才能讓 Claude Code 幫我做出一個實用的東西？
這個很難給固定答案，但根據我陪過的客戶，如果需求清楚，從描述到跑出第一個可用的版本，大概半小時到兩小時之間。後來要微調、改細節，可能再花一兩個小時。第一次通常比你預期的快，但第一次也常常比你預期的混亂。
