第一個問題:你自己最近用 Claude Code 做過什麼真實的東西?

上個月一個做外貿的年輕人,傳了一張收據截圖給我,六千八,附一句話:「老師,這堂 Claude Code 教學我上完了,為什麼我還是不會用?」

我看了那張收據,反問他三件事。付錢之前,你有沒有問過那位老師他自己最近用 Claude Code 做過什麼?有沒有問過你卡住的時候他會不會直接看你的畫面?有沒有告訴他你是做外貿的、完全沒寫過程式?他一個都沒問。他只看到「三小時學會 Claude Code」這行字,刷卡就報名了。

我做易經卦牌決策這麼多年,有一件事一直提醒我:你怎麼問,決定你得到什麼答案。問卦的人如果連自己想解決什麼都講不清楚,抽到再好的卦也沒用。找老師這件事一模一樣。你在付錢之前問對問題,比你上完課再來後悔有用一百倍。

所以今天不談哪堂課好,我教你在掏錢之前,該問老師哪幾個問題。

第一個問題:你自己最近用 Claude Code 做過什麼真實的東西?

這題最好用。你不是問他會不會,你是問他最近做過什麼。一個真的在用的人,會立刻講出一個具體的東西:上週我用它把一份三百列的報價單重寫成自動計算的表、我幫我太太的網拍寫了一支自動回訊息的小工具。他會有細節,會有卡住的地方,會有「後來我發現」。

如果他開始跟你講「Claude Code 是一個革命性的 AI 編程助手」,那你要小心。他在背產品介紹,不是在講他做過的事。差別就在這裡。

第二個問題:我卡住的時候,你會直接看我的畫面嗎?

Claude Code 教學最值錢的地方,從來不是那些能上網查到的指令。是你自己電腦上跑出來的那個看不懂的紅字。那個錯誤只有你這台機器會出現,文件裡查不到,YouTube 上也沒有。

會教的人聽到你卡住,第一反應是「你把畫面給我看」。不會教的人會說「你去看官方文件的 troubleshooting」。你花錢買的,就是有人願意陪你看那個紅字。這一題答不好,後面都不用問了。

第三個問題:我是做這行的,這東西對我這行有哪裡用不上?

這題是照妖鏡。你把你的行業講給他聽,然後問他:對我這種工作,Claude Code 有什麼地方是幫不上忙的?

一個誠實的老師會告訴你限制。他會說,你做的這塊需要接公司內部系統,那部分它幫不了你太多,你可能只能先用在文件整理上。一個只想收你錢的人會跟你說,沒問題,什麼都能做,學了就對了。

會講限制的人,才是真的懂。因為只有用到深的人,才知道邊界在哪。

第四個問題:我完全沒碰過程式,你這堂適合我嗎?

這題是留給你自己誠實的。你要先跟老師講清楚你的底子。如果你連終端機是什麼都沒開過,而對方跟你保證三小時包會,你反而要退一步。

真正替你著想的老師,聽到你零基礎,會先問你想拿它做什麼。如果你只是想整理文件、寫寫文案,他可能會說你其實不用先學 Claude Code,先從別的上手更快。願意把你推去更適合的路,而不是硬把你留在自己課裡的,這種老師難得。

回到那個外貿年輕人。我後來沒有叫他再報一堂課。我陪他坐下來,把他每天最花時間的那件事找出來,是整理各國客戶的報價回信。我們花了四十分鐘,在他自己的電腦上,把那件事做出一個能用的流程。他那天走的時候跟我說,原來不是課的問題,是他一開始問錯人,也問錯問題。

你找 Claude Code 教學之前,先別急著比較誰便宜、誰時數多。先把上面四個問題丟給對方。答得出來的,你再考慮付錢。答不出來的,省下來的錢夠你自己摸索很久了。

常見問題

我怕自己問這些問題會顯得很難搞,老師會不會不想教我?
剛好相反。一個真的想把你教會的老師,聽到你問這些會鬆一口氣,因為他知道你是認真的、會照著做的學生。會被這種問題嚇到、開始打太極的,通常就是你要避開的那種。你不是在找碴,你是在保護自己的六千八。
如果我連要問什麼、要拿 Claude Code 做什麼都還不知道呢?
那你更不該急著報課。先花一個下午,把你每週最煩、最花時間的三件事寫下來。有了這張清單,你去問任何老師都問得出重點,他也才教得到你真正需要的地方。沒有這張清單就報名,等於抽卦之前連問題都沒想好。
網路上免費的 Claude Code 教學那麼多,為什麼還要找老師?
免費資源能讓你知道它「大概能做什麼」,但沒辦法陪你解決你電腦上那個只有你會遇到的問題。付錢找人,買的是那段卡住時有人在旁邊的時間。如果你自學一個月都跨不過某個坎,那堂課的錢其實是幫你省時間,不是浪費。
