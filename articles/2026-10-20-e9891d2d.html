註冊那一段，真正會卡人的三個地方

十月四號下午，教室裡三十二個人，我請大家打開筆電現場註冊 Claude 帳號。十分鐘後有七個人舉手，卡住的點幾乎一模一樣：四個人的信用卡被銀行退掉，兩個人手機驗證碼一直收不到，一個人用公司信箱註冊，驗證信被自家 IT 擋在隔離區。

先把那句最常被問的講清楚：註冊 Claude 帳號不需要信用卡，也不需要美國帳號、美國手機、美國地址。免費方案就是填信箱、收一封驗證信、用台灣手機號碼過一次簡訊驗證，完了。需要刷卡的是付費方案（一個月二十美金，台幣大概六百四）和開發者用的 API 儲值（最低五美金），這兩件事跟「能不能註冊」是分開的兩條路。

很多人真正卡住的不是技術。是他把註冊和付費想成同一件事，於是在還沒看過這個工具長什麼樣子之前，先在心裡算了一年要繳七千多塊，然後停在那裡三個星期。順序反了。

註冊那一段，真正會卡人的三個地方

手機號碼的格式。畫面上先選國碼，台灣是 +886。後面那一欄不要連 0 一起填。手機 0912345678，國碼選好之後只填 912345678。那天兩個收不到驗證碼的，兩個都把 0 留著。改掉之後十秒內簡訊就進來了。

信箱的選擇。Gmail、Outlook、Yahoo 這種個人信箱最單純。公司信箱不是不能用，但如果你們 IT 有擋國外寄件者，你會一直等一封永遠不會到的信。那天那位是做精密模具的，他們公司把所有非白名單的國外來信都丟隔離區，我請他換個人 Gmail，三十秒解決。

地區不用造假。它會問出生年月日，國家那一欄台灣可以直接選 Taiwan。我知道網路上還流傳著要掛 VPN 的說法，那是前幾年的資訊了。現在反而是你掛了 VPN，IP 跟後面的帳單資料對不上，被風控攔下來的機率更高。

刷卡那一關，問題幾乎都在你的銀行這一端

付費方案才需要卡，台灣發的卡可以用。那天四個被退的，原因我當場一個一個問出來。

兩個人的卡沒開海外網路交易。這是台灣多數銀行的預設狀態，卡發下來就是關的。打客服，或自己上網銀找「海外交易」「國外網路交易」這類開關打開，大概五分鐘。

一個人用數位帳戶的簽帳金融卡，裡面只有三百多塊。扣款前會有一筆小額授權測試，餘額不足整筆退。他轉錢進去就過了。

一個人把 Country 選成 United States。他以為非這樣不行。改回 Taiwan，帳單地址填中文或英文都無所謂，下一秒就通了。

API 儲值是另一條路。你如果只是想在網頁上問問題、丟一份 Excel 進去請它幫你看，根本不需要碰 API。API 是給要寫程式接進自己系統的人用的，預付制，最低五美金，用多少扣多少。我帶企業客戶導入的時候，第一個月幾乎不會動用 API，就是用網頁版先把需求摸清楚。

潛龍勿用這四個字，我每次講 Claude 教學都會拿出來

乾卦初九，潛龍勿用。龍在最底下那一爻，還沒到該動的時候，先別動。

我一開始也覺得這四個字很消極，後來帶了幾百場企業諮詢才懂，它講的不是不要動，是「你還沒看清楚自己在哪裡的時候，動了也是白動」。

對應到這件事就很直白：先註冊免費帳號，給自己兩個星期，不要先刷卡。這兩個星期你只做一件事，把你每天重複在做、而且做得很煩的事情，丟三件進去試。報價單格式整理、客戶來信分類、會議錄音抓重點，隨便哪一件都可以。

兩個星期之後你手上會有一個具體答案：它幫你省了幾分鐘，還是它根本幫不上你那個行業。有了這個數字，再決定要不要為了用量上限和比較長的檔案付那六百四。我有個做食品貿易的客戶，兩個星期測下來發現他最需要的其實是整理國外客戶的詢價信，那件事一天幫他省二十五分鐘，他第十五天自己去刷卡了。也有客戶測完說算了，他的工作八成在跑工地現場，用不上。這個「算了」也是有價值的答案，他省下的不只是錢，是三個月的猶豫。

易經不是算命。它逼你把問題問清楚。你原本問的是「要不要信用卡」，問清楚之後會發現，真正該問的是「我要它幫我做什麼，那件事值不值得一個月六百四」。問題換了，答案自己就浮出來了。

最後講一個小細節

那天教室裡最後一個完成註冊的是一位六十一歲的女士，做文具批發。她卡了二十二分鐘，前面全花在手機號碼那個 0 上。註冊完之後她問的第一個問題是：「我想請它幫我寫給日本廠商的回信，可以嗎？」

我說可以。她打完字按下送出，看了螢幕三秒鐘，回頭跟我說了一句：「它怎麼知道要加這句敬語？」

註冊那關其實從來不是門檻。真正的門檻是你有沒有一件具體的事，想交給它試一次。

常見問題

我完全不想付錢，免費帳號能用多久？
沒有期限。免費方案是長期可用的，不是試用期。限制在用量上，問得太密集會提示你稍等一下。如果你是每天問三五個問題、偶爾丟一份文件，免費方案可以撐很久。我有學員用了四個多月才升級，因為後來開始丟整份合約進去看。
我手上只有簽帳金融卡，不是真的信用卡，可以嗎？
可以，但有兩個條件。一是要開啟海外網路交易功能，很多數位帳戶預設是關的。二是帳戶裡要有足夠餘額，因為扣款前通常會有一筆小額授權測試，餘額剛好或不足都會被整筆退掉。被退了不要一直重刷，連刷三次以上銀行可能會把那張卡暫時鎖住，反而更麻煩。
那些賣「代註冊帳號」「共享帳號」的，可以買嗎？
不要。註冊本身免費又簡單，花錢買等於花錢買風險。共享帳號你不知道同一個帳號裡還有誰的對話紀錄，你丟進去的客戶資料、報價、合約也就不只你看得到。企業要用的話更不能這樣，資安稽核第一關就過不了。自己花四分鐘註冊比較實在。
