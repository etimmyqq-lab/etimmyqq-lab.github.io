一條毛利 9.4% 的產線，和兩個待了十一年的人

上個月有家做汽車模具的公司，採購把我的課程報價單退回來，紅筆圈了兩行，旁邊寫：「請確認是否為同一位講師。」

週二那堂是「Claude Code 實作：用自然語言跑完一份報價分析」，週四那堂是「易經卦牌決策工作坊」。她以為排課系統出錯了。

我打電話過去解釋，講到一半自己也笑了，因為這個問題我被問過大概十幾次，每次答得不太一樣。那天我試著講短一點：Claude Code 幫你把事情算完，易經卦牌幫你確認這件事該不該做。她停了兩秒，說「所以真的是同一個人」。

就這樣。不過這個回答其實偷懶了。真正的原因，要講那家公司老闆七月做的那個決定。

一條毛利 9.4% 的產線，和兩個待了十一年的人

七月中，他想把一條做沖壓件的產線外包出去。想了快一年，開不了口。

我陪他用 Claude Code 把 2023 到 2025 三年的報價紀錄跑一遍，1,842 張單，要算的是真實毛利：扣掉返工工時、假日加班、模具攤提。這件事以前他請會計算過，算了兩週，結論是「資料太亂，算不出來」。

那天從打字到跑出數字，含他中間改了兩次需求，大概 40 分鐘。他原本認為那條線毛利在 22% 上下。跑出來 9.4%。

數字很乾淨。決定一點也沒有變乾淨。

因為那條線上有 6 個人，其中兩個待了 11 年。9.4% 這個數字告訴他這條線不賺錢，但沒有告訴他「所以要叫兩個待了十一年的人走」是對的。他看著螢幕，說了一句我記得很清楚的話：「數字我早就知道了，我只是沒有膽子算。」

AI 把他躲了一年的東西，40 分鐘攤在桌上。然後就卡在那裡。

這種卡住，我在企業 AI 導入的現場看過很多次。工具跑得很快，人沒跟上。

起卦之前那三行字

隔了一週，我們做了一次卦牌。

很多人以為易經就是抽一張看結果。不是。起卦之前，你得把問題寫成一句話，而且是一句你敢承認的話。這一步我會要求寫在紙上，不准含糊。

他寫第一次：「我該不該把沖壓線外包。」

我說這不是你的問題。你已經知道該外包了，數字上週就算完了。

第二次：「外包之後人員怎麼安排比較不傷害公司。」

我說這也不是。你在問技術問題，你卡的不是技術。

第三次他寫了比較久，寫完把紙推過來，上面是：「我如果留下這條線，是為了公司，還是為了我自己不想當那個開口的人。」

那張紙推過來的時候，卦還沒起。

我們後來還是起了，水澤節，講的是節制與界線。他解出來的方向是「要留的不是產線，是人」。最後他把那 6 個人裡的 4 個轉去做模具維修（那塊本來就缺人），兩個待最久的留在產線直到合約收尾，隔年三月。外包的事九月簽了。

但我想說的不是卦準不準。我想說的是那張紙。問題改到第三行的時候，他其實已經決定了。卦只是讓他不好意思再裝作不知道。

兩件事練的是同一塊肌肉

Claude Code 有一個特性，我上課一定講：它會非常忠實地把你寫錯的需求做出來。

你說「幫我整理這份報價表」，它會整理，整理成它猜的樣子。你說「算出每張單扣掉返工和加班後的毛利，返工工時在 F 欄，加班在 H 欄，攤提用月初分攤，有缺值的那幾列先列出來不要自己補」，它做的就是你要的。

差別不在工具，在那句話的精確度。

易經那邊是反過來的一面鏡子。它不給你數字，它只有在你把問題問對的時候才有用。問題含糊，你拿到的卦辭就會被你隨便解成你想聽的話。

一個是你寫得不清楚，它就做錯；一個是你問得不清楚，你就解錯。兩個都在逼同一件事：先定義問題。

所以我的課表長那樣不是排錯。先學會怎麼讓機器把事情做完，再學會怎麼確認這件事值得做。順序顛倒也行，很多學員是先上易經那堂才去碰 Claude Code 教學的，效果一樣。

如果今天只能帶走一個習慣

開 Claude Code 之前，先在記事本打三行：

我要的結果是什麼（一句話，不超過三十個字） 什麼算成功（一個可以驗的數字或條件） 哪些檔案不准動

這三行花你兩分鐘，省掉的是來回改五次。

然後，在做任何會影響到人的決定之前，也寫一行：我真正在怕什麼。

這一行不用給 AI 看。

常見問題

易經不就是算命嗎，跟 AI 放在一起不會很怪？
會，我自己當初也覺得怪。不過卦牌在我這裡的用法不是預測，是逼你把問題寫成一句你敢承認的話。那家模具廠老闆寫了三次才寫對，前兩次都在躲。AI 算得出毛利 9.4%，算不出「我不想當那個開口的人」。這兩塊不衝突，是接在不同位置。
我完全沒寫過程式，上 Claude Code 教學跟得上嗎？
跟得上，因為你打的是中文。我課上的要求不是你會不會寫程式，是你能不能把需求講到讓人聽懂。那家公司的老闆到現在也不會寫 Python，他會的是把「毛利怎麼算」講成七八句具體條件。難的一直是後面那件事。
那我到底該先上哪一堂？
看你現在卡在哪。如果你手上有一堆算不出來的資料，先上 Claude Code 那堂。如果你資料都有、報表都看過、就是不敢做決定，那你缺的不是工具。我見過最多的是第二種。
