你真正需要先會的，不是語法

不需要。我做 Claude Code 教學這幾年，真的學到能自己動手的那幾位中小企業主，沒有一個是先讀完 Python 才開始的。順序反而常常是倒的：先用它解決掉三五件自己真正煩的事，過程中被迫看懂幾行程式在幹什麼，半年後才回頭去補語法。

上週三晚上，桃園一家做食品包裝袋印刷的二代把兩本書放到我旁邊。公司 26 個人，他爸還管著業務。一本 Python 入門，翻到第 47 頁，夾了張便利貼；另一本書套都還沒拆。他說買了五個月了。

我問他，這五個月你到底想用 Claude Code 做什麼？

他回答得很快，快到我知道這件事煩他很久。出貨明細對帳。工廠那台印刷機每天吐一份生產紀錄，欄位是英文縮寫；ERP 匯出的訂單是中文欄位。兩個 Excel 要用訂單編號對起來，找出數量不一致的。他每天晚上做這件事，大概 40 分鐘，對到眼睛花。

我說，你現在打開筆電，我們半小時把它做掉。

他有點抗拒。他說我才看到第 47 頁，我連 pandas 是什麼都還不確定。

那天晚上總共花了 35 分鐘。他一行 Python 都沒寫。

你真正需要先會的，不是語法

那 35 分鐘裡，他卡住的地方一次都不是程式。

第一次卡住是路徑。他說「檔案就在桌面啊」，可是要告訴終端機「桌面」在哪，他打不出來。後來我教他在檔案總管上面那條網址列點一下、整串複製，貼進去就好。這件事花了四分鐘，之後他再也沒卡過。

第二次卡住是描述。他一開始打的是「幫我對帳」。四個字。結果它猜了一組欄位對應，猜錯了兩個。我請他改成「這兩個檔案用訂單編號對起來，數量欄位在 A 檔叫 QTY、在 B 檔叫實出數量，找出不一致的列」。改完一次就對。

第三次卡住是紅字。中間有一行報錯，紅色的，他反射動作是把視窗關掉。我按住他的手說，你把那段紅字整段複製，貼回去給它看，然後只要打一句：這是什麼意思，怎麼修。他照做，它自己改了，跑過了。

路徑、描述、不怕紅字。這三件事沒有一件需要 Python。而這三件事學會了，你剩下的問題就只是「想做什麼」而不是「會不會做」。

那天我們實際打了什麼

我把當晚的順序寫下來，因為很多人問我第一次該打什麼。

先在桌面開一個資料夾，兩個 Excel 丟進去。開 PowerShell，`cd` 到那個資料夾，輸入 `claude`。

第一句話不要叫它做事，叫它先看：「這個資料夾裡有兩個 Excel，請先把每個檔案的欄位名稱和前三列資料讀出來給我看，不要修改任何檔案。」

這句話是整晚最重要的一句。因為你會在它動手之前，親眼確認它有沒有看懂你的資料。多數新手的災難都發生在跳過這一步。

第二句才是任務，而且結尾要加煞車：「請用訂單編號把兩個檔案對起來，列出數量不一致的，輸出成一個新的 Excel。動手前先把做法寫成步驟給我看，我說 OK 你才執行。」

「我說 OK 你才執行」這七個字，我在每一場教學都會講一次。它把一個你不熟的工具，變成一個會先報告再行動的助手。

他看完步驟，發現它打算直接覆蓋原始檔。他自己說了一句：不行，另存新檔。然後它改了。

那一刻我覺得他已經會了。不是會 Python，是會用。

蒙卦講的是這件事

蒙卦的卦象是山下出泉。泉水剛從山腳冒出來，量很小，方向也還不知道，它沒有先畫好一張地圖再流。它是碰到石頭繞一下、碰到低處往下走，流著流著才成了河。彖辭接一句「果行育德」。果行在前，育德在後。先動，能力是在動的過程裡長出來的。

很多人學 AI 工具的順序是反的。先把德育好，才敢行。於是買了書，翻到第 47 頁，五個月。

我不是說基礎不重要。我自己後來也去補了不少東西，而且補的時候輕鬆很多，因為每個概念我都已經有一個踩過的痛點可以掛上去。看到 for 迴圈的時候我不是在背語法，我是在想「哦，上次那 1,300 個檔案就是這樣被分完的」。

有些老闆問我，那我完全不懂程式，會不會被它唬？會。這是真的風險，我不想騙你。所以那句「先給我步驟」不是禮貌，是你唯一的檢查點。你看不懂程式，但你看得懂「我要覆蓋你的原始檔」這句中文。

那位二代後來自己弄了一個排程，每天早上八點自動跑對帳。上個月他跟我說，他那本 Python 書終於翻過第 47 頁了，而且這次看得懂。

他沒說謝謝，他說的是：早知道就不買書了。我笑了一下沒接話。書沒有錯，順序有錯。

常見問題

完全不會程式，用 Claude Code 會不會把我的檔案弄壞？
有可能，所以兩件事一定要做。第一，開始前把原始資料複製一份到別的資料夾，這是最便宜的保險。第二，每個任務都加上「動手前先把做法寫成步驟給我，我說 OK 你才執行」。你看不懂程式，但你看得懂它說要覆蓋哪個檔案。我教過的人裡，出事的幾乎都是省掉這兩步的。
那我到底什麼時候該去學 Python？
當你發現自己開始想改它寫出來的東西，而不只是想要結果的時候。這個訊號很明顯，你會突然想知道「它剛剛那段為什麼要跑兩次」。那時候去學，一本書大概兩三週就讀得完，因為每一頁你都有對應的實際經驗可以掛。在那之前硬讀，多半停在第五十頁左右。
第一個練習該挑什麼題目比較不會挫敗？
挑一件你自己手動做超過 20 分鐘、而且每週至少做一次的重複工作。檔案改名、兩份表格對照、把一堆資料依日期分資料夾，這類都很適合。不要一開始就挑「幫我做一個系統」，那種題目你判斷不了它有沒有做對，卡住也不知道卡在哪。要挑那種你一眼就能驗收結果對不對的。"
