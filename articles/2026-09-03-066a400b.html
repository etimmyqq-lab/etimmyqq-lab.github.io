先想清楚：你要它「幾點做、做什麼」

上週二下午，一個在彰化做汽車零件外銷的老闆傳來一段對話截圖。他兒子幫他設定了 Claude Code，每天早上自動整理前一天的詢價信、把報價單初稿擬好。他很滿意，但問我一句：週六週日我根本沒進公司，它還在那邊跑、還在寫東西，我看週一回來一堆檔案，反而要花時間清。有沒有辦法讓它週一到週五跑、週末休息，就像真的員工那樣？

有，而且不難。這篇就把做法講清楚。我用的是 Windows 內建的工作排程器，不用裝任何額外東西。

先想清楚：你要它「幾點做、做什麼」

很多人一上來就想設排程，結果卡在一個地方：排程只是決定「什麼時候按下開關」，它不會幫你想「按下去要跑哪一段」。所以第一步不是打指令，是先把那件每天要做的事，寫成一個 Claude Code 能一次跑完的任務。

我通常會先開一個資料夾，裡面放一個純文字檔，把要它做的事一條一條寫下來。像那位老闆的狀況，我幫他寫的是：讀取今天信箱匯出的詢價 csv、比對報價歷史、產出三份報價草稿存到 drafts 資料夾。寫得越具體，它跑出來的東西越不用你回頭清。

然後在命令列測一次，確定它一次能跑完、不會中途停下來問你問題。這步不能跳。排程最怕的就是它半夜跑到一半卡住等你回答，結果整晚就停在那。你可以在指令裡加上非互動模式的參數，讓它遇到選擇時走預設值，不要停下來問。

用工作排程器設定「只在平日跑」

確定任務能自己跑完之後，剩下的就是告訴 Windows：週一到週五早上九點，幫我按一次開關。

最快的方式是開 PowerShell，貼這一行：

`schtasks /Create /TN "ClaudeCode-Weekday" /TR "C:\path\to\run.bat" /SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 09:00`

拆開來看：`/TN` 是這個排程的名字，你自己取；`/TR` 是要跑的東西，我習慣包成一個 bat 檔，裡面就一行 `claude` 加上你的任務指令；`/SC WEEKLY` 是每週；`/D MON,TUE,WED,THU,FRI` 這串就是關鍵，明確指定只有這五天，週六週日它就不會動；`/ST 09:00` 是每天幾點。

如果你不想打指令，也可以直接開「工作排程器」這個內建程式，點右邊的「建立工作」，在觸發程序那頁選每週、勾週一到週五，一樣的效果，只是用滑鼠點。

那個 bat 檔長什麼樣？大概就這麼兩三行，第一行切到你的專案資料夾，第二行呼叫 claude 帶上你要它做的事。真的沒有很複雜。

設完之後我會叫客戶手動先跑一次確認：在排程器裡右鍵那個工作，選「執行」，看它有沒有乖乖跑完、檔案有沒有出現在該出現的地方。確認過再放著讓它自己每天跑。

週末休息這件事，其實藏著一個東方的老道理

那位老闆設完之後跟我講了一句話，我覺得比技術本身更值得寫下來。他說：我一開始的想法是，反正它是機器，能跑就讓它一直跑，二十四小時七天不停不是賺到嗎，幹嘛還讓它休息。

我請他想一件事：真正讓你頭痛的，是它跑得不夠多，還是它跑出一堆你週一沒空看、只好堆著的東西？

他愣了一下，說是後者。

易經裡有一卦叫節，澤水節，上面是水、下面是澤。澤能裝多少水是有限的，滿了就溢出來，所以要有節制、要有度。彖傳講「天地節而四時成」，意思是天地就是因為有節奏、有停頓，才有春夏秋冬四季，萬物才長得出來。如果一年到頭都是夏天，作物反而死。

我做企業 AI 導入這幾年，看過太多人把工具當成越多越好。買最貴的方案、開最多的自動化、什麼都想讓它跑。結果不是效率變高，是產出多到人消化不了，最後那些自動生成的東西堆在資料夾裡沒人看，跟沒做一樣，甚至更糟，因為你還要花時間分辨哪些有用。

讓 Claude Code 週末休息，表面上是一個排程設定，骨子裡是你在替這個工具設一個「度」。它配合你的節奏，而不是你去追它的產出。你週一進公司，看到的是五份剛好可以處理的草稿，不是三十份積壓兩天的檔案。

節卦還有一句我很喜歡，「不節若，則嗟若」。不懂得節制，最後就是唉聲嘆氣。這話放在今天用 AI 的人身上，一點都不過時。

所以那位老闆的問題，答案是有，做法就上面那幾行。但真正的重點不是怎麼讓它停，是你有沒有想清楚，你要的到底是它多做一點，還是你自己能好好消化它做的東西。

設好排程之後，他週末真的不再收到一堆檔案通知了。他說週一早上打開電腦那五份草稿，感覺就像有個員工幫你把事做好放桌上，而不是一個停不下來的機器在角落嗡嗡叫。

常見問題

我電腦週末關機的話，排程還會等到週一才跑，還是那兩天的就跳過了？
跳過。工作排程器是到那個時間點看電腦有沒有開機、任務要不要跑，週六週日你本來就沒排它跑，所以什麼都不會發生。週一開機到九點它才動。如果週一你剛好晚開機、錯過九點，可以在排程設定裡勾「錯過就在開機後補跑一次」，它會自己補上。
我不是用 Windows，是 Mac，這套還能用嗎？
概念一樣，只是工具換成 Mac 內建的 cron 或 launchd。cron 設平日跑的寫法是 `0 9 * * 1-5`，那個 `1-5` 就是週一到週五。原理跟 Windows 那串 MON 到 FRI 完全一樣，都是明確告訴系統只有這五天按開關，其他細節網路上一搜就有。
那如果我想更細，比如只有週三跑一次比較重的整理，其他天跑輕的，做得到嗎？
做得到，就是建兩個排程。一個叫平日輕量、設週一二四五；另一個叫週三重整、只設週三，跑不同的 bat 檔。它們互不干擾。我會建議先把最基本的每天一次跑順，用一兩週習慣了，再來加這種分工，不然一次設太多，哪個出問題你很難查。
