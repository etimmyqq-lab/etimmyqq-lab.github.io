為什麼「它到底是什麼」會決定你怎麼用它

上週四中午，一個在台中做五金零件批發的會計傳了張 Excel 截圖給我，問了一句我這半年被問過至少二十次的話：Claude Code 到底是聊天機器人，還是寫程式的工具？我能不能拿它來幫我對帳？

我先把答案講白：Claude Code 是一個會讀你電腦裡檔案、也會動手改檔案的工具，你用中文跟它講話，它幫你把事情做完。它能處理 Excel，但方式跟你想的不一樣。它不是打開 Excel 幫你點滑鼠，而是直接讀你的 .xlsx，照你講的規則算完、再產出一份新的檔案。

這個分類問題，其實比你想的重要。

為什麼「它到底是什麼」會決定你怎麼用它

我發現大部分人卡住，不是因為工具難，是因為一開始把它歸錯類。

如果你以為 Claude Code 是聊天機器人，你會把 Excel 裡的數字一格一格複製、貼到對話框裡，問它「幫我算這個」。資料一多就貼不完，貼進去它也容易看漏。你會覺得這東西不好用，然後放棄。

但如果你知道它是一個能直接讀檔案、動手改檔案的工具，你的用法會完全不同。你不貼數字，你把整個 Excel 檔案丟給它，跟它說：這是我三月的進貨明細，幫我按廠商分類、把每家的總額算出來、產一份新的對帳表。它會自己打開檔案、自己算、自己存一個新檔給你。

易經裡有個講法叫「正名」。孔子說名不正則言不順。聽起來很老派，但這件事放到 AI 工具上剛剛好。你怎麼稱呼一個東西，決定你怎麼跟它相處。你把 Claude Code 叫成聊天機器人，你就只會跟它聊天；你把它認成會幫我動手的助手，你才會把真正的工作交給它。名字錯了，用法就全錯。

那台中那位會計，後來怎麼做的

我請她先別急著問怎麼算，先做一件事：把她每個月手動對帳的步驟，用中文一條一條寫下來。她寫了六條，大概是這樣：

第一，打開廠商寄來的對帳單和自己的進貨明細。第二，一筆一筆比對品項和金額。第三，把對不上的標紅色。第四，算出這個月每家廠商應付總額。第五，把有問題的挑出來另外做一張。第六，存成當月的對帳報告。

寫完她自己愣了一下，說原來我每個月做的事這麼清楚。

我跟她講：這六條就是你要給 Claude Code 的指令。你不用會寫程式，你把這六句話貼給它，再把兩個 Excel 檔案指給它看，它就照著做。她試了第一次，卡在第三步，因為她說「標紅色」它不知道要標哪個欄位。她補了一句「金額差超過十塊的那一列整列標紅」，第二次就跑對了。

這就是 Claude Code 教學裡我最想讓人先懂的一件事：它不是猜你心裡想什麼，它是照你講清楚的話做事。你講得含糊，它做得含糊；你把六條步驟講明白，它一條都不會漏。

它不是更聰明的計算機

我要老實講一個容易誤會的地方。很多人試過一次覺得好用，就開始想把所有事一次丟給它，結果又失望。

Claude Code 適合的是有規則、你自己講得清楚的工作。對帳、分類、把十個格式亂七八糟的報價單整理成一張表、從一堆訂單裡撈出某個條件的資料，這些它做得又快又穩。但如果你連自己都說不清楚要什麼，比如「幫我看看這份報表有沒有問題」，它會給你一個很空泛的答案，因為你沒告訴它「問題」的定義是什麼。

這其實又回到易經那句話。問卦的人如果自己心裡一團亂，卦象再準也沒用，因為你根本不知道自己在問什麼。它跑出來的東西好不好，一半看它，另一半看你有沒有把問題想清楚。工具負責算，把問題問對這件事，永遠是你的。

那位會計後來每個月對帳從一個下午變成大概二十分鐘。她跟我說最大的改變不是快，是她終於把自己每個月在做什麼，講清楚了一次。

就這樣。它是不是聊天機器人，其實沒那麼重要。重要的是你有沒有把它當成一個要好好交代清楚的幫手。

常見問題

我完全不會寫程式，用 Claude Code 幫我做 Excel 會不會太難？
不會，你需要的不是程式能力，是把步驟講清楚的能力。你怎麼跟一個新來的工讀生交代對帳流程，就怎麼跟它講。真正的門檻是你願不願意花五分鐘，把自己平常在做的事寫成一條一條，而不是寫程式。
它會直接改掉我原本的 Excel 檔案嗎？我怕弄壞正本。
你可以要求它產一份新檔案、不要動原檔，直接跟它說「不要改原檔，另存一份新的」就行。保險起見，處理重要檔案前先自己複製一份備份，這是好習慣，跟用不用 AI 沒關係。
那它跟直接在對話框貼數字請 AI 算，差在哪？
差在資料量和穩定度。貼幾筆數字進對話框當然可以，但你有三百筆的時候貼不完，貼進去也容易漏。Claude Code 直接讀整個檔案，不用你手動搬資料，資料越多這個差別越明顯。
