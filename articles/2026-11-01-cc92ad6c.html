我後來都先問一句：這筆錢換回了多少人時

十月二十三號上午，桃園一家做汽車零件模具的廠商，財務主管把一張列印出來的帳單推到我面前。三萬七千四百元，收款方寫著 Anthropic。她問我：這是什麼軟體，一個月要三萬七？我們的 ERP 一年才十二萬。

問句本身就是問題所在。她把它歸類成軟體，所以拿軟體的價錢去比。比下來當然嚇人。

我那天沒有急著講 Claude Code 能做什麼。我先說：這筆錢的性質不是軟體訂閱，比較接近電費或委外加工費。它是變動成本，用多少付多少，停下來就不收。你拿它跟一次買斷的 ERP 比，從第一句話就錯了。

她沉默了一下，說：那我要怎麼跟股東講。

我後來都先問一句：這筆錢換回了多少人時

那間公司兩個工程師，原本每週要把十七台 CNC 匯出的稼動率 csv 手動併成一份 Excel，再貼到主管群組。一個人做，每週大概九小時。導入之後他們寫了一支腳本把合併跟異常標記自動化，現在剩一點五小時，因為還是要有人瞄一下有沒有怪數字。

我把這件事攤開算給她看。一個月省下三十小時，時薪抓八百五，是兩萬五千五。帳單三萬七千四。

第一個月是虧的，虧一萬一千九。

我老實講了這個數字，她臉色不太好看。但我覺得這件事一定要先講，因為第二個月開始情況會變，而你如果第一個月用漂亮數字騙過去，第二個月就沒有信用可以用了。

第二個月他們又多做了兩件：報價單的規格比對、模具履歷的關鍵字查找。第三個月帳單反而降到兩萬四。

降下來的原因很白：重複的事情腳本化之後，就不需要每天再問一次 AI。你花錢買的不是每天的答案，是一支一次寫完的腳本。腳本寫完就不再花錢。

這跟訂閱制是反方向的。訂閱是只要你還在用就一直收，而這種用量計價的東西，用得好的團隊帳單會自己往下走。我會把這句話寫進給股東的那頁，因為它是整份說明裡最反直覺、也最容易被記住的一句。

給會計的那張表只有三欄

任務名稱、導入前人時、導入後人時。就這三欄。

重點是只填你真的量過的任務。沒量過的不要估，估出來的數字在股東會上一被追問就垮。寧可表上只有兩列，兩列都站得住。

然後算單位成本。那份稼動率日報，導入前一份要七千六百五十元的人時，現在是一千兩百七十五元人時加上大約九百元的 API 用量。你給會計看的應該是這個數字，不是月費總額。會計看到變動成本的本能反應是問單位成本，你把單位成本直接端上去，話就接得順了。

具體要記在哪個科目，去問你自己的會計師，每家公司的帳務結構不一樣。我能講的只是比較對象要換掉。

損卦講的其實就是這件事

易經第四十一卦是損。很多人看到這個字就覺得不吉利，但損的意思不是虧，是把一邊的資源挪到另一邊。卦辭說「二簋可用享」，祭祀用兩個器皿就夠了，不用鋪張。減到剛好，誠意不減。

我在企業 AI 導入的場子裡講這個卦講過很多次，因為老闆跟股東真正怕的從來不是花錢。他們怕的是花了錢，不知道換到了什麼。損卦的結構是損下益上，有來有去，你說得出來去掉了什麼、換到了什麼，這件事就立得住。說不出來，再便宜的支出都會被砍。

我也見過反面的。去年一家做包材的，老闆把每月上限壓在五千元以內，規定工程師一天只能問十次。結果那個工程師改成先在紙上把問題想清楚再問，問題的品質變高了，答案也變得能用。

這不算壞事。節制有時候真的會逼出東西。

但他同時也放棄了那種漫無目的的試，而很多真正有價值的用法是試出來的，不是規劃出來的。取捨就是取捨，沒有兩邊都要的版本。

那天離開前，財務主管把那張帳單翻過來，在背面手寫了三欄。她說下次股東會要帶這張去。字有點歪。

常見問題

我們公司完全沒量過人時，根本填不出那張表，怎麼開始？
挑一件你每週都要做、而且做到會煩的雜事，接下來兩週用手機計時器記它花多久。兩週就夠了。我知道這聽起來很笨，但沒有這個底數，你任何關於划不划算的說法都只是感覺，而股東會上感覺是最先被打掉的東西。
第一個月就是虧的，這樣要怎麼報？
就報虧的。同時附上你預估第幾個月翻正、以及憑什麼這樣預估。我見過最有效的講法是：這筆支出的特性是用量會隨著腳本累積而下降，我會每月回報帳單數字給各位看趨勢。願意被每月檢視，比任何保證都有說服力。
會計問我這筆錢有沒有上限，我該怎麼回？
有，而且你應該主動設。做法是每個人發一把獨立的 API key，Console 裡可以看到每把 key 的用量，誰花的、花在哪個專案一清二楚。把這件事講出來，會計要的其實不是省錢，是可控。能分帳的支出在她眼裡就不是黑洞。
