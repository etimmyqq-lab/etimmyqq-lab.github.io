中年轉職，第一個要學的不是工具名字，是「把問題講清楚」

上週六早上課後，一個做壽險做了十九年的大哥留下來，五十一歲，聲音壓得很低。他說公司組織調整，他大概撐不到年底，想趁還有點積蓄轉職學 AI。然後他問了一句我這半年聽過至少三十遍的話：老師，我是不是該先學 Claude Code？聽說會叫 AI 寫程式的人最值錢。

我沒有直接回答該或不該。我反問他：你現在手上，有沒有一件事是你每週都要做、做起來很煩、而且你講得出它的步驟的？

他愣了一下，說有，他每個月要把七十幾個客戶的保單到期日、繳費狀況、生日，從三個不同系統抄到一張 Excel，再手動排出這個月要打哪些電話。做一次要一個下午。

我說，那你該學的第一個東西，就藏在這句話裡。不是 Claude Code 這個名字，是「把你講得清楚的重複流程交給 AI」這件事。

中年轉職，第一個要學的不是工具名字，是「把問題講清楚」

我知道很多人期待的答案是一個工具清單：先學這個、再學那個、三個月後你就能接案。老實說我給不出這種清單，因為它對你沒用。

中年轉職跟二十五歲學東西最大的不同，不是記性，是你其實已經有十九年的專業在身上。壽險大哥懂核保、懂客戶心理、懂什麼時候該打電話。這些是二十五歲的人沒有的。問題從來不是他學不學得會 AI，是他把 AI 當成一個要從零開始的新行業，而不是一個能接到他既有專業上的工具。

所以我後來都這樣講：中年轉職學 AI 工具，第一個該學的，是能立刻套進你現在會的事的那個。對壽險大哥來說，那是能聽懂人話、幫他把抄資料流程講清楚並自動化的工具。至於這件事最後是用對話式 AI 完成，還是要動到 Claude Code 寫一支腳本，那是第二層的問題，不是第一天要煩惱的。

那 Claude Code 到底適合誰、什麼時候學

我不是說 Claude Code 不用學。我自己天天用。我只是覺得它不該是大部分中年轉職者的第一站。

Claude Code 這種能直接在你電腦上讀檔案、改檔案、跑指令的工具，威力很大，但它預設你已經知道「你要它做什麼」。它像一個很強的助手，可是助手再強，你得先說得出任務。壽險大哥如果第一天就開 Claude Code，他會卡在一個更前面的問題：他還不習慣把腦袋裡那個「每個月抄資料」的流程，拆成 AI 聽得懂的步驟。

所以我給的順序通常是這樣。先花兩個禮拜，用對話式 AI 把你手上最煩的三件事講給它聽，逼自己練「把工作說清楚」這個能力。這個能力練起來，你會發現它比任何工具都值錢。等你能一口氣講清楚「我要它做什麼、輸入是什麼、我想要的結果長怎樣」，這時候再進 Claude Code，你會用得很順，因為你缺的從來不是工具，是把問題結構化的習慣。

這也是為什麼我做企業 AI 導入的時候，第一場從來不教軟體操作，先花一整個下午陪老闆和主管把「我們公司到底哪些流程在浪費人」講清楚。工具是最後才進場的。

我用易經的卦序來看這件事

我知道講到這裡有人會皺眉，覺得學個 AI 扯什麼易經。但這個框架我用了好幾年，它幫我看清楚一件事：學習有先後，跳著學會摔跤。

易經有一篇叫序卦傳，講的就是六十四卦為什麼是這個順序。乾坤之後不是馬上接大成的卦，接的是屯卦，屯是萬物初生、根還沒扎穩、什麼都亂糟糟的階段。序卦傳的意思是，事情有它該有的次第，你不能因為看到別人在收成，就想跳過扎根那一段。

中年轉職學 AI 也是。大家看到的是「會用 Claude Code 的人能接案賺錢」那個收成畫面，於是想直接跳到那裡。但中間那段把自己的專業和 AI 對接、練習把問題講清楚的過程，就是你的屯卦，是根。跳過去，你就算硬把工具學會了，也接不到你十九年的專業上，那才是真的浪費。

易卦不會告訴你該學哪個軟體，這種事它管不著。但它會逼你把「我為什麼要學這個、我現在在哪個階段」想清楚。壽險大哥後來沒有先碰 Claude Code。他先花了三個禮拜，把每個月那張 Excel 的整理流程，一步一步講給 AI 聽，練到能自動生出打電話清單。上個禮拜他傳訊息給我，說那個下午現在只要二十分鐘。他還沒轉職成功，但他第一次覺得，AI 這件事跟他有關係了。

就從那件你每週都在煩的小事開始。名字叫什麼，先別管。

常見問題

我五十歲了，數學也不好，Claude Code 這種要打指令的東西我真的學得會嗎？
學得會，但我建議你先別急著從它開始。Claude Code 需要打的不是傳統那種要背語法的程式碼，比較像用中文交代任務。真正的門檻不是年紀或數學，是你有沒有先練好「把一件事講清楚」。這個你做壽險十九年早就會了，只是還沒對著 AI 練。先從對話式工具練兩三週，再進 Claude Code 會順很多。
大家都說會 AI 才有競爭力，我是不是動作太慢了？
沒有。真正慢的是那種學了一堆工具名字、卻沒有一件事真的自動化的人。你有十九年的行業專業，這是速成班學不來的。與其焦慮進度，不如挑一件你每週都在做的煩事，把它交給 AI，做成一個能動的成果。一個能動的小東西，勝過十個聽過名字的工具。
中年轉職學 AI，到底要不要花錢去報那種三個月接案班？
看它教什麼。如果課程一開始就塞你一堆工具操作、卻沒先幫你搞清楚「你的既有專業能怎麼跟 AI 對接」，我會保守一點。中年轉職最大的本錢是你原本的專業，好的學習應該是把 AI 接到那上面，而不是要你假裝自己是個二十五歲的工程新人從頭來過。
