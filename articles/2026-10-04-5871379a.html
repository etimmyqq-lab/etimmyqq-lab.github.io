卦辭他沒讀，直接丟給 AI

九月中，台南一家做不鏽鋼水槽代工的老闆，把一支水山蹇卦的卦辭貼進 Claude Code，打了一句「幫我分析這個卦對我接這張單的影響」，得到 2,400 字的回覆。他把那段文字印出來給我看，問我：這樣是不是迷信加科技的亂燉？我看完跟他說，是，但亂的地方不在易經，也不在 Claude Code，在那句話。

先講他的狀況。工廠 48 個人，一個新客戶要下一張單，吃掉大概 35% 的產能，一次簽兩年。他糾結了三個星期。糾結的點不是要不要賺這筆錢，是他說不上來哪裡怪。

這種「說不上來」的狀態，是我用易經卦牌的時機。不是因為卦會告訴他答案，是因為卦會逼他把「怪」講成一個具體的問題。

卦辭他沒讀，直接丟給 AI

蹇卦的彖辭有一句：「見險而能止，知矣哉。」白話講，看得到危險而且停得下來，這叫聰明。卦辭又說「利西南，不利東北」，西南是平地，東北是山，意思是往順的那邊走，不要硬爬。

他沒讀。他把整段複製，貼進 Claude Code，問它這個卦什麼意思。

那 2,400 字我大概看了一半。內容是對的，蹇的卦象、六爻的解釋、歷代注疏的看法，都有。問題是這些東西網路上到處都是，Claude Code 寫出來的跟任何一本易經入門書差不多。而且它完全不知道他的工廠、他的客戶、他的應收帳款長什麼樣。

這就是亂燉。你拿一個會讀程式、會跑資料的工具，去做它最沒必要做的事：解卦。然後拿一個專門逼你問對問題的框架，當成答案來讀。兩個工具都用反了。

把卦當問診單，不是當診斷書

我跟他說，重來。這次卦辭不給 AI 看，給你自己看。

「見險而能止」，那你的險在哪？他想了一下，說：這個客戶我沒做過，35% 太集中，萬一它付款慢，我現金會卡住。

好，這就是問題了。蹇卦沒有回答任何事，它只是讓他把三個星期的「怪」講成一句話：這個客戶的付款風險，比它帶來的營收重要。

接下來才輪到 Claude Code。他公司有三年的應收帳款紀錄，一個 ERP 匯出的 CSV，大概 9,800 筆。我請他打開 Claude Code，指令大概是這樣：

讀取這份應收帳款檔，找出過去三年裡，首年訂單占當年產能超過 25% 的客戶。比較這些客戶的平均付款天數，跟其他客戶差多少。用表格列出，順便標出有沒有逾期超過 60 天的紀錄。

跑了不到四分鐘。結果有兩個客戶符合「首年就占 25% 以上」，這兩家的平均付款天數是 47 天，其他客戶平均 12 天。其中一家在第二年有兩筆逾期超過 90 天。

他看著那張表沒說話。然後說，對，那家後來退出了，他差點忘了。

兩個工具各管一段

說實話，這個結果我事先也不知道。我不知道他的資料裡有這個模式，他自己也不知道，不然不會糾結三個星期。

卦做的事，是把「我覺得怪」變成「我擔心付款風險」。這一步 Claude Code 做不到，因為它不知道你在怕什麼，它只知道你輸入了什麼。

Claude Code 做的事，是把「我擔心付款風險」變成「過去兩個同類客戶付款慢 35 天，一個有 90 天逾期紀錄」。這一步卦做不到，因為卦不會讀 CSV。

我常用一個比喻，卦是問診單，Claude Code 是檢驗室。問診單不會告訴你得了什麼病，它決定你抽哪管血。檢驗室不會問你哪裡痛，它只回報數字。你拿問診單去檢驗室要他們解釋你的症狀，那是亂燉。你拿檢驗報告去問醫生「我該不該怕」，也是亂燉。

後來他沒有拒絕那張單。他回去跟客戶談，要求 30% 訂金，付款條件從月結 60 天改成 30 天。客戶答應了。這個決定不是卦給的，也不是 Claude Code 給的，是他自己做的，只是他這次知道自己在怕什麼，而且有數字可以講。

所以到底算不算迷信

我自己的看法是，迷信的定義是把因果交給一個你無法檢驗的東西。

如果你抽到蹇卦，然後因為「卦說不利東北」就不接單，那是迷信。如果你抽到蹇卦，然後把卦辭丟給 AI 問它什麼意思，再把它寫的當成分析結果，那是迷信換了個比較科技的殼。

但如果你抽到蹇卦，被那句「見險而能止」逼得說出你到底在怕什麼，然後用 Claude Code 把那個「怕」對到自己三年的真實資料上，看它成不成立，這個過程裡每一步你都檢驗得了。卦的角色跟一個很會問問題的顧問一樣，差別是它不收鐘點費。

我做企業 AI 導入這幾年，看過的失敗案例裡，有一大半不是工具不會用，是老闆說不出自己想知道什麼。資料全部都在，工具也都裝了，就是問不出那個問題。易經在這件事上幫了我不少忙，這點我以前不太敢講，怕被當成神棍。現在講得比較自在，因為我手上有一疊像上面那樣的表格。

那位老闆後來傳訊息給我，說他把那張 47 天對 12 天的表貼在辦公室牆上。他說以後業務再來說有大單，他就指那張表。

卦牌他收在抽屜裡。

常見問題

我沒學過易經，也不會看卦辭，這方法對我有用嗎？
有用，而且門檻比你想的低。你不需要會解六爻。你只要讀卦辭和彖辭那幾句白話翻譯，然後回答一個問題：這幾句話讓我想到我目前狀況的哪一個部分？想到什麼就寫下來，那就是你要拿去跑資料的問題。查卦辭用任何一個易經網站或 AI 工具都可以，但「想到哪一部分」這一步只能你自己做，這也是整個方法裡唯一不能外包的地方。
直接問 Claude Code「我該不該接這張單」不是更快嗎，為什麼要繞一圈抽卦？
你可以試試看，大概率會得到一份四平八穩的利弊分析，營收面、風險面、產能面各講一段，看完跟沒看一樣。原因是 Claude Code 不知道你在怕什麼，它只能把所有面向都講一遍。卦的作用是逼你先選一個面向，選完再去跑資料，答案就會尖銳得多。不一定要用卦，你用任何能逼你收斂問題的方法都行，只是我用卦用得順手。
卦象結果要不要讓 Claude Code 知道？
我的做法是不給。卦辭給它看，它就會花力氣去解卦，產出一堆你不需要的注疏。你只要把從卦辭想出來的那個具體問題給它，加上你的資料檔案。它不需要知道你為什麼問這個，它只需要把問題對到資料上。卦留在你這邊，資料分析交給它，分工清楚，才不會變成亂燉。
