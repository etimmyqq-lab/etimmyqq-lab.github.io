入門實戰

不講概念、不背名詞。
四週、八小時，把 Claude Desktop 從「另一個聊天視窗」，變成幫你讀檔、做報告、跑流程的工作夥伴。

 

01　給你的

你已經追了三個月教學影片，
但還是不知道從哪裡開始。

ChatGPT 訂了、Claude.ai 也用過——每次都是「問一句、答一段、複製貼上回 Word」。產能感覺有提升一點，但離「AI 幫我把事做完」還很遠。這堂課把 Claude Desktop 裡你沒用到的 80%——Projects、Artifacts、檔案讀取、MCP 工具——一次補齊。

 

02　四週進度

從裝起來，到能上工。

W1

把 Desktop 用對

Claude Desktop 安裝、模型選擇、長對話技巧、Artifacts 怎麼讓它直接產出可用文件。把「會聊天」升級成「會交付」。
W2

Projects：你的專屬助理

用 Projects 建一個「懂你公司、懂你客戶、懂你寫作風格」的常駐助理。知識庫怎麼上傳、System Prompt 怎麼寫、怎麼避免它一本正經地胡說八道。
W3

MCP：讓 Claude 真的會做事

接上檔案系統、瀏覽器、Google Drive、Notion——讓 Claude 不只是回答你，是直接幫你開檔、查資料、寫進文件。從「問它」變成「派它」。
W4

做完一個自己的工作流

每人帶一個自己的真實任務（寫週報、做提案、整理會議記錄、分析客戶資料皆可）上課，最後一週直播逐案優化、收工。
